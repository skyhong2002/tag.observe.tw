# Share-card font

`NotoSansTC-Share.woff` is derived from the Traditional Chinese face (index 3)
of Noto Sans CJK Bold, installed as `NotoSansCJK-Bold.ttc`. License: SIL OFL 1.1,
included in `NotoSansTC-LICENSE.txt`.

Generated with fontTools: retain U+0020–024F, U+2000–206F, U+2E80–9FFF,
U+FF00–FFEF, remove optional layout features, save as WOFF. This is a server
asset for `next/og`, not a web font served to readers. Its ~7.1 MiB size does
not contribute to page JavaScript or image download sizes.
