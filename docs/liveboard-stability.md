# 即時看板長時間運作修正（2026-10-07）

巡查跑馬燈原本直接把每次更新的全部紀錄放進 CSS 無限動畫，以紀錄數決定 duration、以整條文字寬度決定移動距離。更新過程同時改變長度及 duration，使仍在播放的動畫重新對應時間與位置，造成跳動及速度不穩；同來源同階段的重試紀錄也可能重複列出。

現在 `CrawlMarquee` 每輪固定使用一份資料，完成整輪後才換下一份。每來源／階段只顯示最新結果，最多 40 筆。位移依每幀經過的時間計算，標準速度為每秒 32 像素，與資料數量及文字長度無關；只保留一條 animation-frame 鏈，在卸載時取消。位置每輪歸零，不累積長時間位移；背景分頁停止前進，恢復後不補播；過長幀間隔最多採計 100 毫秒。第二份文字僅供循環銜接並設定 `aria-hidden`，每份寬度至少為視窗寬度，避免短清單在同一畫面顯示多份相同內容。

斷線提示原本在單次請求失敗後立即顯示，下一次成功就消失。`createFeedPoller` 現在對每輪失敗請求等待一秒並重試一次；連續三輪仍失敗才顯示斷線，成功立即恢復。每次更新都有互斥保護，延遲回應不會讓多次輪詢使用同一個 cursor、重複處理文章或退回舊 cursor。失敗時保留既有畫面，卸載後忽略尚未完成的回應。

驗證包含六小時模擬、清單寬度變動、重複紀錄、背景／前景切換、動畫停止與重新掛載、暫時失敗重試、持續斷線及恢復，以及重疊輪詢／卸載時的延遲回應。相關 21 項測試通過；Tailscale 預覽能載入看板與 API，瀏覽器確認跑馬燈使用單一位移控制且沒有殘留的 CSS 跑馬燈動畫。六小時是程式模擬測試，並非在使用者機器實際開啟六小時。

前端事件／首頁載入測試移到 `web/test`，由前端的 TypeScript bundler 設定檢查；Vitest 與 Biome 同時納入該目錄。`npm run typecheck` 現在依序檢查後端及前端，兩者皆通過。

這份紀錄描述本機修正與驗證，不表示正式站已部署。
