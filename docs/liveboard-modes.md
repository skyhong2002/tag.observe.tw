# Liveboard 一般看板與 Advanced

對應 https://github.com/skyhong2002/tag.observe.tw/issues/4 。本文件描述本機實作，不表示已部署。

`/liveboard/` 預設顯示主要新聞、最新收錄與「我的 Tag 追蹤」。`/liveboard/advanced/` 顯示內文相似新聞、議題新進報導、事件延續與各家標題；爬蟲狀態及更新紀錄預設收合。兩頁都有明確的模式入口與暫停／恢復更新按鈕。一般版不掛載進階分析、圖表、跑馬燈或自動輪播。

主要新聞沿用 `/api/v1/events?limit=12` 的事件排名與既有 `selectEventLead` 代表標題選擇，每個事件至多一則，最多六則。不足時依 `/api/v1/liveboard` 的收錄 ID 由新到舊補入。已選事件的代表報導 ID、去除常見前綴及標點後相同的標題、API 已知的相似群組會去重；另外顯示三則最新收錄。這只是呈現規則，沒有修改新聞相似度或事件分群演算法；尚未完成分析的新聞仍可能屬於同一事件。

標題直接開啟站內新聞閱讀頁的新分頁，保留看板。新聞閱讀頁提供原文入口；本次未修改全文或權限政策。無文章 ID 的舊事件使用既有站內搜尋備援。一般版顯示來源、刊登／首次收錄時間或明確標示的「事件快照」時間與 Tags；未知時間明示待確認，不以當下時間冒充。

新聞與個別 Tag 每 30 秒檢查，事件每三分鐘檢查。請求八秒逾時，失敗一秒後重試一次；每個資源只有一條有效的更新鏈，暫停／卸載後忽略晚到的回應。瀏覽器在背景時不輪詢，回到前景立即檢查。一次失敗重試完仍失敗即顯示該資源的保留／重試狀態，成功自動恢復。

主要新聞與最新收錄保留仍在候選集合內的新聞位置，只替換離開集合的格位；使用固定卡片／列高度、不做輪播或強制重新載入。列表數量有上限，不會隨輪詢附加增長。成功但空白的新聞／事件快照保留最後可讀內容，並明示沒有新進新聞或事件未更新。相似內文及議題更新附資料時間；缺內文仍可查看標題、新聞／議題頁。

追蹤使用現有 `/api/v1/tags/:tag/articles?hours=24&limit=8`，顯示每個 Tag 近 24 小時最新三則；不只是過濾看板有限的新聞樣本。最多五個精確 Tag，保存在 `tag-liveboard-follows-v1` localStorage；兩模式與同源分頁共用。儲存失敗會提示僅此頁有效。API 暫時失敗時保留既有結果；成功查詢為空則明示近 24 小時無符合新聞。這是瀏覽器內追蹤，沒有新增帳號同步、推播或伺服器寫入。

驗證：`web/test/liveboard-view.spec.ts` 涵蓋事件排序、去重、固定格位、縮短列表、六小時（720 次）更新模擬、不完整回應、議題內文待收錄與追蹤設定限制。既有 poller 測試涵蓋重疊請求、重試、卸載與恢復。六小時是程式模擬，非正式站六小時實測。
