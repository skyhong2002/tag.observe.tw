# 長期觀察（#19，第一版）

`/tracking/` 保存版本化的條件：主標籤 AND（搭配詞1 OR 搭配詞2…）。
完全比對現存文章標籤，不使用 AI、別名推測、人工逐事件歸併或修改事件串接規則。

- 事件頁「長期觀察」以 seed 帶入前兩個主要標籤。畫面、分享與儲存清單皆改用回傳的固定標籤；seed 不是持久定義。
- 網址保存條件，可分享、加入書籤；最多30組個人清單存在此瀏覽器 localStorage，沒有帳號同步。
- 重開儲存的觀察顯示最近180個台北日期，資料隨現有爬蟲更新；沒有新增爬蟲或背景工作。
- 可選最多366天，逐日統計可切換日／週／月圖，按柱狀圖回看到期末。媒體表顯示前20個來源，JSON提供全部。
- 每篇文章必須符合完整條件，以文章id去重；不同文章id的轉載仍各自計數。
- 獨立事件必須在同一小時的主要標籤符合條件；保留原事件id，不合併事件，也不把整個事件的所有文章算進統計。
- 回看會重新查詢截至該日的文章與事件代表標題。事件詳情連結開啟完整事件，頁面會明示。

## 介面共用

導覽、切換、建議輸入、表格、媒體連結、文章列及方法說明沿用站內元件。
統計卡與區塊標題由事件頁抽出為 DataSections；TrendChart 由轉載統計頁抽出，兩頁使用同一個圖表元件。
表單沿用進階文章查詢的共用樣式；沒有 tracking 專屬 CSS 或獨立配色。

## 資料界線

文章來源包含歷史匯入。事件快照始於2026-09-28，較早報導可能只有文章統計。
標籤缺漏、不同寫法或未達到事件分群門檻會漏掉相關內容。零篇不能當作媒體未報導的證據。
回看使用現存標籤及刊登日期，不是當時收錄狀態的封存；後來的補收或標籤修正可能改變過去日期的數字。
此版沒有跨條件的關係圖、通知排程或帳號同步。

## API與負載界線

`GET /api/v1/observations`：參見 [API文件](api.md)。
每次查詢最多25000篇文章、20000個候選事件串、1000個符合事件串；每條SQL限5秒。
觸發上限或資料錯誤回503，不發布截斷統計。每程序最多2個新查詢並行，24組快取、60秒。
使用既有article_tags(tag,published_at)索引，沒有schema變更或資料庫寫入。

## 隔離預覽

`tools/preview-observations.ts` 僅註冊本次唯讀端點，其餘公開GET API轉給既有本機gateway，移除Cookie與Authorization。
不註冊寫入、登入或管理操作，不啟動worker、migration或crawler。
預設API監聽本機獨立port；開發模式可用既有rewrite。
正式編譯的隔離預覽可設定TAG_PREVIEW_UI_ORIGIN指向本機Next standalone，
TAG_PREVIEW_HOST綁定Tailscale位址，TAG_PREVIEW_API_PORT設定對外port，
Next的TAG_API_ORIGIN指向此gateway。API、頁面及資產走同一入口；/auth/me明確回傳停用登入。
不得替正式服務改port或重啟。
