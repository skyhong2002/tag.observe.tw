# 媒體頁與文字雲

`/media/<media>/` 是報導與保存內文的共同入口。每頁 60 篇，預設隱藏摘要，可勾選「顯示摘要」。標題、縮圖與文字雲都在站內導覽；外部來源有獨立的外連圖示。

桌機的側欄顯示文字雲與媒體資料；手機先顯示文章，以「媒體資料與文字雲」按鈕展開側欄內容。媒體資料沿用既有收錄統計與來源對照表，沒有資料時顯示缺值，不推估媒體發稿量。

## 文字雲資料

- `GET /api/v1/media/:media/keywords?hours=168`：預設近 7 天，指定時間篩選時與列表的時段一致。「全部」列表仍顯示近 7 天的文字雲。
- 依刊登時間取最新最多 2000 篇；回應揭露 `sampledArticles`、`capped` 與統計起訖。UI 在截斷時標示「取最新」。不受列表分頁或文字搜尋影響。
- 合併文章標籤與標題關鍵詞，每篇每詞只計一次。標題沿用跨媒體近 7 天標籤建立的詞彙表；排除既有通用詞、新聞分類與純數字日期詞。
- 回傳最多 50 詞，依文章數遞減。詞彙表在 gateway 內快取 10 分鐘，回應快取 2 分鐘；只讀取已存的標題與標籤，不抓取原站或讀取正文。
- 點詞透過 `q` 搜尋同媒體的標題、摘要或完整標籤，所以搜尋結果可比文字雲的詞頻範圍更廣。篩選條件隨閱讀頁連結保留，返回時回到原列表位置。

## 排版參考

參考 [skyhong2002/infovore 的 cloud.ts](https://github.com/skyhong2002/infovore/blob/main/src/output/cloud.ts)：平方根字級、從中心向外的螺旋排列、碰撞檢查與縮小重試。本專案改以報導篇數為權重，並依容器面積調整字級；SVG 文字可操作，另提供完整詞頻列表。過長、無法容納的詞不強行塞入雲中，仍可在詞頻列表找到。

測試涵蓋詞頻去重、跨頁範圍、取樣上限、搜尋條件、文字重疊與邊界；瀏覽器檢查摘要開關、手機展開、篩選返回及實際 SVG 字框。
