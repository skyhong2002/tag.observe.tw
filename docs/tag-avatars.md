# 人物標籤與素描頭像

標籤名稱正好是 Wikidata 上某位人物的名稱或別名時，標籤頁會顯示這個人的素描頭像和一行身分（現任職位、政黨），並附上原照片的作者與授權。資料由 `tools/tag-avatars.ts` 產生，管理員在 `/admin/avatars/` 確認、換圖或隱藏。

## 流程（`app/src/avatars/`）

1. **比對人物**（`wikidata.ts`）：`wbsearchentities` 的結果中，名稱或別名與標籤**完全相同**、且 P31 為人類（Q5）的項目才算。同名多人時取 Wikipedia 條目最多的一位，並標為「待確認」。順便記下國籍（P27）、職業（P106）、政黨（P102，沒有結束時間的才算現任）與職位（P39，沒有結束時間 P582 的視為現任）。
2. **收集照片**：依序取 Wikidata 照片（P18）、Commons 上標註「描繪此人」（P180）的檔案、此人的 Commons 分類（P373），檔名含 cropped／portrait／肖像的優先，最多 20 張，各下載 1200px 縮圖。
3. **認人**（`vision.ts`）：YuNet 偵測人臉與五官，SFace 以五官對齊後算身分向量。第一張照片中，在其他照片最常以主角出現的那張臉就是本人（處理 P18 是合照的情況）；之後主角與本人相似度低於 0.363 的照片一律不用。沒有 P18 時，至少兩張照片要彼此認得出同一人。
4. **篩選**（`portrait.ts`）：主角臉寬至少 80px；第二大的臉達主角六成大小算合照，不用；頭肩裁切範圍內還有別人的臉算「旁有他人」，仍列入候選但分數 ×0.7。
5. **評分**：臉大小 25%、正面程度（鼻子是否在兩眼中間、兩眼是否水平）20%、光線 20%、清晰度（Laplacian 變異數）15%、像本人 10%、偵測信心 10%。同一張照片的不同裁切（Commons 的「X (cropped).jpg」，或對齊後的臉在 32px 下相關係數 ≥ 0.85）只留一張。
6. **素描**：以臉為中心裁出 2.1 倍臉高的正方形 → U²-Net（u2net_human_seg）去背，只留頭寬到肩寬範圍內最大的一塊 → 白底 → colour dodge 鉛筆素描 → 256px WebP，存在 `tag_avatar_candidates`。原照片不保存。存的圖以透明度記線條深淺（太淡的照片拉到最深 1% 全不透明，最多 3 倍），灰階記人物剪影。
8. **顯示**：頭像是網站橘色（`brand-600`，深色模式 `brand-400`）透過 CSS mask 畫出的線條，沒有底色或外框。API 依 `theme` 即時產生遮罩：`light` 只有線條；`dark` 人物範圍填滿、線條鏤空，深色背景上才是正片而不是負片。
7. **狀態**（`tag_people.status`）：`auto` 自動用第一名；`review` 第一名分數低於 0.55 或有同名人物，仍先顯示第一名；`nophoto` 沒有可用照片；`none` 不是人物；`chosen`／`hidden` 是管理員選定或隱藏，之後重跑不覆蓋（`--force` 除外）。

三個 ONNX 模型（YuNet、SFace、U²-Net，合計約 207 MB）不進 git，第一次執行時下載到 `AVATAR_MODEL_DIR`（預設 `~/.cache/tag-avatars/models`），以 SHA-256 驗證。推論限制在 2 個執行緒，因為網站跑在同一台主機；一張照片約 0.1–0.7 秒，一個標籤（含網路）約 10–20 秒。

## 執行

```sh
node --env-file=.env tools/tag-avatars.ts 賴清德 苗博雅   # 指定標籤
node --env-file=.env tools/tag-avatars.ts --top 100       # 最近 7 天最多文章、30 天內沒查過的 100 個標籤
```

`--force` 連同管理員選定、隱藏過或 30 天內查過的標籤一起重跑。Wikimedia API 一律帶描述性 User-Agent，遇到 429／5xx 會退避重試。

## 管理與 API

- `/admin/avatars/`：依狀態列出人物標籤，每人最多三張候選與分數；點候選圖改用那一張，「不顯示頭像」隱藏。每次變更寫入 `tag_people_log`。
- 公開：`GET /api/v1/tags/{tag}/person`（人物、身分、頭像網址與授權）、`GET /api/v1/tags/{tag}/avatar`（WebP），見 [api.md](api.md)。
- 頭像網址帶版本參數（最後檢查／審核時間 + 名次），重跑或換圖時會變，圖檔本身快取一天。

## 授權

Commons 照片的授權各不相同（公有領域、CC BY、CC BY-SA、政府「須標示來源」）。素描是衍生作品，因此標籤頁一律連結原檔頁、作者與授權；CC BY-SA 的素描應以相同授權提供。
